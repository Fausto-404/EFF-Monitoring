# EFF-Monitoring v2.2.2 本地验收记录

验收日期：2026-10-23；环境：本机独立 Docker Compose 项目 `eff-monitoring-v2-2-2-test`，PostgreSQL 与 API/Worker/前端容器。此记录仅代表该测试环境，不等同于生产环境性能承诺。运行凭据与完整备份文件均不纳入 Git。

## 旧版备份还原与告警工作台

- 通过前端 Nginx 上传并成功还原旧版 JSON 备份（571,177,585 字节，约 545 MiB）；还原后有 5,853 条告警、62,441 条消息、26,876 条审计日志。
- 默认 50 条/页时，直接 API 冷请求约 20 ms、热请求约 3 ms；1000 条/页约 45 ms，深页约 11 ms。以上仅是本机采样值，不包括完整页面渲染。
- 真实浏览器中，告警工作台显示 5,853 条；刷新后列表请求约 115 ms，压缩传输约 4.3 KB、解压响应约 20.2 KB。切换到 1000 条/页后请求约 259 ms，压缩传输约 68 KB、解压响应约 400 KB。浏览器控制台无错误。
- 导入后另建 1 条测试告警，因此当前隔离环境总数为 5,854 条。未复现“刷新约 3 分钟”，但尚未在用户原生产网络和硬件上复测。
